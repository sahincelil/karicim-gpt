# LEGION Plugin CloneForge

See the full implementation guide in [integrations/plugin-cloneforge/README.md](../integrations/plugin-cloneforge/README.md).

## Preview

After deployment, visit `/plugins.html` for the searchable provider registry and `/api/plugin-catalog` for its read-only JSON API.

## Scope

The first release inventories 94 provider namespaces observed in the connected tool environment. It is not a claim that proprietary third-party plugins have been copied, nor that each provider is live-connected. Provider-specific adapters and health checks are separate, reviewable work items.
